An entry for the make.fun bounty [The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6): a program that writes a single short pickup line, the kind an AI agent could actually say out loud to a person, to `/output/entry.txt`.

## The line

> I set one reminder for today: find the person smiling at the corner table. It just went off. Can I sit down?

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library.
